# 3D Арена — Social

Вариант C для сравнения с [основным сайтом](https://3d-arena.ru/). Создан 18.09.2026 по публичным данным клуба.

[Открыть сайт](https://dubasv.github.io/3d-arena-social/) · [Аудит](docs/AUDIT.md) · [План эксперимента](docs/EXPERIMENT.md)

## Локальный просмотр
Открыть index.html в браузере или из папки проекта запустить `python3 -m http.server 8080` и открыть http://localhost:8080. Сборка и установка зависимостей не нужны.

## Файлы
- index.html — содержание, тарифная таблица, FAQ, все ссылки.
- styles.css — адаптивное оформление.
- pricing.js — 20 сочетаний тарифов с ночной акцией.
- attribution.js — допустимые метки, срок 30 дней, обозначение варианта.
- app.js — калькулятор, меню, галерея, события.
- config.js — настройка счётчика; в демонстрации отключён.
- assets — реальные фотографии с сайта клуба, фирменный знак и локальные шрифты Manrope (OFL приложена).

Проверка логики: `node tests/core.test.cjs`. Все фото и шрифты локальные, загрузка исходного сайта для показа не нужна. Права на бренд и фото остаются у их правообладателей; публикация исходников не передаёт права третьим лицам.

## Границы готовности
Кнопки ведут в действующий LANGAME, Telegram, телефон и карты. Калькулятор не бронирует и не резервирует место; выбранные параметры нужно повторить в LANGAME. Тарифы зафиксированы по публичному сайту, наличие мест и итоговая стоимость проверяются там. Главный домен и рекламные кампании не изменялись.

GitHub Pages — демонстрация, noindex. Внешняя аналитика выключена; перед рекламным запуском подтвердить измерение оплаченных броней и тарифы. Не снимать noindex и не включать рекламу автоматически. План в docs/EXPERIMENT.md.
